prefix `mcp__plugin_hyperspace-engine_hyperspace__` (for example
`mcp__plugin_hyperspace-engine_hyperspace__upsert_work_item`). Every tool answers against the
project's `.hyperspace/graph.db`.

## complete_workitem

Close a Task Graph row as done by independent verification, synchronously. The touched list (paths this work created, modified or deleted) IS the statement of work — no narrative field exists. Returns exactly one of done \| refused \| unverifiable \| already_done.

| Argument | Type | Required |
|---|---|---|
| `project` | string | yes |
| `external_id` | string | yes |
| `touched` | array of TouchedPath | yes |
| `idempotency_key` | string | yes |
| `proposer_identity` | string | yes |
| `proposer_surface` | string | yes |
| `manual_attestations` | array of ManualAttestation | no |

Nested types (`ManualAttestation`, `TouchedPath`) are defined in `hyperspace/verify/claim.py`.
